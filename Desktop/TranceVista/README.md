
# TravelPlanner

A full-stack Travel Itinerary Planning System built using:

- ASP.NET Core Web API
- Angular
- MySQL
- JWT Authentication
- Clean Architecture

## Features

- Destination Search
- Budget Travel Planning
- Day-wise Itinerary
- Favorites
- Smart Recommendations

## Tech Stack

### Backend
- ASP.NET Core
- Entity Framework Core
- MySQL

### Frontend
- Angular
- TypeScript

### Database
- MySQL
